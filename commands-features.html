3. First Login and Peaceful Mode

Our server has a special feature called Peaceful Players.

Everyone starts in personal peaceful mode by default. This allows you to build, mine, farm, and explore without normally being targeted by hostile mobs.

If you want normal Survival combat, type:

/peaceful survival

To return to peaceful mode, type:

/peaceful

Your personal setting should remain saved between sessions.

Important: This is not Creative mode. You still collect resources and play Survival normally.

Peaceful protection is not guaranteed against every possible situation, so continue to be careful around hostile mobs.

4. Useful Commands

You can type these commands in Minecraft's chat window.

CommandWhat It Does
/spawnTeleport to the server's main spawn
/sethome nameSave your current location
/home nameTeleport to one of your saved homes
/homesView your saved homes
/delhome nameDelete a saved home, once enabled
/peacefultoggle between personal peaceful and sufvival mode
/peaceful survivalSwitch to normal Survival combat
/peaceful peacefulSwitch to personal peaceful mode
/backpack or '/bp'Open your personal backpack, if enabled

You can currently have 15 saved homes.

For example:

/sethome house

Later, type:

/home house

This returns you to the location you saved.

You can also save locations such as mine or farm.

Good idea: Set a home near your base as soon as you get established!

5. Helpful Server Features

🎒 Backpacks

Everyone has access to a personal backpack with 54 storage slots.

This gives you extra space for mining, building, and exploring.

📦 Automatic Inventory Sorting

NeatSort automatically organizes your inventory and chest contents when you close them.

No need to manually rearrange everything!

🌾 Easier Farming

The Scythe plugin allows automatic crop replanting.

  • Use a hoe to harvest supported mature crops.
  • You must have the required seeds.
  • Your hoe loses durability during harvesting.

🪓 Easier Tree Cutting

Timberella allows you to chop down trees more easily.

  • Works with stone, iron, gold, diamond, and netherite axes.
  • Does not work with wooden axes.
  • Your axe loses durability when used.

🔎 WhatIsThis

Look at blocks, crops, and other supported objects to see useful information automatically.

For example, you can see how far along a crop is in its growth.

💥 Explosion and Fire Protection

We've adjusted the server to make accidental damage less frustrating.

  • Creepers should not destroy the landscape.
  • Fire spreading is disabled.
  • TNT is still available for mining, so use it carefully.

🎒 Sorter's Satchel

This special item helps you quickly put things away.

Instead of opening every chest, the satchel searches nearby storage and deposits items into chests that already contain matching items.

It's especially useful after mining, farming, or gathering supplies.

Crafting Recipe

Arrange these ingredients in a crafting table:

LeatherEnder PearlLeather
Copper IngotBundleCopper Ingot
LeatherHopperLeather

You can use the crafted satchel or open its menu with:

/sortersatchel open

The command requires you to own a satchel.

Remember: The satchel can potentially interact with nearby chests belonging to other family members, so be careful when using it near someone else's storage.

8. A Few Family Server Tips

  • Respect other players' houses, farms, and storage.
  • Set a home near your base.
  • Use the online map when exploring.
  • Remember that your backpack provides extra storage.
  • Your inventory is configured to stay with you when you die.
  • If a command doesn't work, ask for help. We're still adjusting some permissions.
  • Most importantly, have fun!
