Java & BedrockConsole DNS instructions

1. Connecting to the Server

Minecraft Java Edition (Windows, Mac, Linux)

  1. Open Minecraft Java Edition.
  2. Select Multiplayer → Add Server.
  3. Enter playmc.stewnet.com as the server address.
  4. Save and join.

Minecraft Bedrock Edition (Windows, Phones, Tablets)

  1. Open Minecraft Bedrock Edition.
  2. Select Play → Servers → Add Server.
  3. Enter:
    • Server Name: Stewart Family
    • Server Address: playmc.stewnet.com
    • Port: 19132
  4. Save and connect.

PlayStation, Xbox, and Nintendo Switch

These consoles normally don't allow adding custom servers directly. We use a free service called BedrockConnect to work around this limitation.

See the next section.

2. Connecting from PlayStation, Xbox, or Switch

BedrockConnect works by changing your console's DNS settings so you can select our private server.

DNS Addresses

PlayStation 4 / PlayStation 5

  • Primary DNS: 45.55.68.52
  • Secondary DNS: 8.8.8.8

Xbox / Nintendo Switch

  • Primary DNS: 104.238.130.180
  • Secondary DNS: 8.8.8.8

PlayStation 5 Setup

  1. Open Settings → Network.
  2. Select Settings → Set Up Internet Connection.
  3. Select your connected network and open Advanced Settings.
  4. Change DNS Settings to Manual.
  5. Enter the PlayStation DNS addresses above.
  6. Save and test your connection.

PlayStation 4 Setup

  1. Open Settings → Network → Set Up Internet Connection.
  2. Choose Wi-Fi or LAN.
  3. Select Custom.
  4. Choose your network.
  5. Select Automatic for IP Address Settings.
  6. Select Do Not Specify for DHCP Host Name.
  7. Select Manual for DNS Settings.
  8. Enter the PlayStation DNS addresses above.
  9. Leave MTU on Automatic and Proxy Server on Do Not Use.
  10. Test your connection.

Xbox Setup

  1. Open Settings → General → Network Settings.
  2. Select Advanced Settings → DNS Settings.
  3. Choose Manual.
  4. Enter the Xbox DNS addresses above.
  5. Save your settings.

Nintendo Switch Setup

  1. Open System Settings → Internet → Internet Settings.
  2. Select your connected network.
  3. Choose Change Settings.
  4. Set DNS Settings to Manual.
  5. Enter the Switch DNS addresses above.
  6. Save.

Joining Our Server After Changing DNS

  1. Start Minecraft.
  2. Open Play → Servers.
  3. Select a compatible featured server, such as The Hive, Lifeboat, Mineville, Enchanted, or Galaxite.
  4. The BedrockConnect server selection menu should appear.
  5. Choose to connect to a custom server.
  6. Enter:
    • Address: playmc.stewnet.com
    • Port: 19132
  7. Save the entry if possible, then connect.

If the special menu doesn't appear, restart Minecraft and try again.

Troubleshooting: BedrockConnect is a third-party service, and console updates sometimes interfere with it. Current instructions and help are available at:

https://github.com/Pugmatt/BedrockConnect

To return your console's network settings to normal, change DNS back to Automatic.
