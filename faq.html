A FEW THINGS TO KNOW

Frequently asked questions

A quick answer before your next adventure.

Whitelist required — before you connectSend Terry your player name first so he can add you to the whitelist. This server is for Stewart family members only.
Who can join?

Stewart family members only. Send Terry your player name before connecting so he can add you to the whitelist.

Can Java and Bedrock players play together?

Yes. Use playmc.stewnet.com. Java port: 25565. Bedrock port: 19132. See the Connect page for device instructions.

Is this Creative mode?

No. This is Survival. Everyone starts in personal peaceful mode by default, but you still collect resources. Peaceful protection is not guaranteed in every situation.

How do I switch personal peaceful mode?

Use /peaceful survival for normal Survival combat, /peaceful peaceful for personal peaceful mode, or /peaceful to toggle. Your setting should remain saved between sessions.

How many homes and backpack slots do I have?

You can currently save 15 homes. Your personal backpack has 54 storage slots. Use /sethome name and /home name. The guide lists /backpack or /bp, if enabled.

What happens when I die?

Your inventory is configured to stay with you when you die.

Do I need map mods?

No. The online map works in a browser. Xaero’s Minimap and World Map are optional client-side Java mods. Console and Bedrock players cannot use these Java mods.

Why does a command not work?

Some permissions are still being adjusted. Ask for help. The guide qualifies /delhome as “once enabled” and the backpack command as “if enabled.”

What if the console server menu does not appear?

Restart Minecraft and try again. BedrockConnect is a third-party service and console updates can interfere. The Connect page links to current help. Set DNS back to Automatic to return the console’s network settings to normal.

Can TNT or the satchel affect other people’s builds?

TNT is still available for mining, so use it carefully. The Sorter’s Satchel can potentially interact with other family members’ nearby chests. Respect their storage.
