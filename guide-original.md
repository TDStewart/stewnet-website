# Stewart Family Minecraft Server
## Getting Started Guide 🎮

Welcome to our family Minecraft world! We're playing Survival together, with a few extra features to make building, exploring, farming, and storing items easier.

**Minecraft Server:** playmc.stewnet.com
**Online World Map:** https://map.stewnet.com

**Java Port:** 25565
**Bedrock Port:** 19132

Java and Bedrock players can play together on the same server!

---

## 1. Connecting to the Server

### Minecraft Java Edition (Windows, Mac, Linux)

1. Open Minecraft Java Edition.
2. Select **Multiplayer → Add Server**.
3. Enter `playmc.stewnet.com` as the server address.
4. Save and join.

### Minecraft Bedrock Edition (Windows, Phones, Tablets)

1. Open Minecraft Bedrock Edition.
2. Select **Play → Servers → Add Server**.
3. Enter:
   - Server Name: Stewart Family
   - Server Address: `playmc.stewnet.com`
   - Port: `19132`
4. Save and connect.

### PlayStation, Xbox, and Nintendo Switch

These consoles normally don't allow adding custom servers directly. We use a free service called **BedrockConnect** to work around this limitation.

See the next section.

---

## 2. Connecting from PlayStation, Xbox, or Switch

BedrockConnect works by changing your console's DNS settings so you can select our private server.

### DNS Addresses

**PlayStation 4 / PlayStation 5**

- Primary DNS: `45.55.68.52`
- Secondary DNS: `8.8.8.8`

**Xbox / Nintendo Switch**

- Primary DNS: `104.238.130.180`
- Secondary DNS: `8.8.8.8`

### PlayStation 5 Setup

1. Open **Settings → Network**.
2. Select **Settings → Set Up Internet Connection**.
3. Select your connected network and open **Advanced Settings**.
4. Change **DNS Settings** to Manual.
5. Enter the PlayStation DNS addresses above.
6. Save and test your connection.

### PlayStation 4 Setup

1. Open **Settings → Network → Set Up Internet Connection**.
2. Choose Wi-Fi or LAN.
3. Select **Custom**.
4. Choose your network.
5. Select **Automatic** for IP Address Settings.
6. Select **Do Not Specify** for DHCP Host Name.
7. Select **Manual** for DNS Settings.
8. Enter the PlayStation DNS addresses above.
9. Leave MTU on Automatic and Proxy Server on Do Not Use.
10. Test your connection.

### Xbox Setup

1. Open **Settings → General → Network Settings**.
2. Select **Advanced Settings → DNS Settings**.
3. Choose **Manual**.
4. Enter the Xbox DNS addresses above.
5. Save your settings.

### Nintendo Switch Setup

1. Open **System Settings → Internet → Internet Settings**.
2. Select your connected network.
3. Choose **Change Settings**.
4. Set DNS Settings to Manual.
5. Enter the Switch DNS addresses above.
6. Save.

### Joining Our Server After Changing DNS

1. Start Minecraft.
2. Open **Play → Servers**.
3. Select a compatible featured server, such as **The Hive, Lifeboat, Mineville, Enchanted, or Galaxite**.
4. The BedrockConnect server selection menu should appear.
5. Choose to connect to a custom server.
6. Enter:
   - Address: `playmc.stewnet.com`
   - Port: `19132`
7. Save the entry if possible, then connect.

If the special menu doesn't appear, restart Minecraft and try again.

**Troubleshooting:** BedrockConnect is a third-party service, and console updates sometimes interfere with it. Current instructions and help are available at:

https://github.com/Pugmatt/BedrockConnect

To return your console's network settings to normal, change DNS back to Automatic.

## 3. First Login and Peaceful Mode

Our server has a special feature called **Peaceful Players**.

Everyone starts in personal peaceful mode by default. This allows you to build, mine, farm, and explore without normally being targeted by hostile mobs.

If you want normal Survival combat, type:

`/peaceful survival`

To return to peaceful mode, type:

`/peaceful`

Your personal setting should remain saved between sessions.

**Important:** This is not Creative mode. You still collect resources and play Survival normally.

Peaceful protection is not guaranteed against every possible situation, so continue to be careful around hostile mobs.

## 4. Useful Commands

You can type these commands in Minecraft's chat window.

| Command | What It Does |
|---|---|
| `/spawn` | Teleport to the server's main spawn |
| `/sethome name` | Save your current location |
| `/home name` | Teleport to one of your saved homes |
| `/homes` | View your saved homes |
| `/delhome name` | Delete a saved home, once enabled |
| `/peaceful` | toggle between personal peaceful  and sufvival mode |
| `/peaceful survival` | Switch to normal Survival combat |
| `/peaceful peaceful` | Switch to personal peaceful mode |
| `/backpack` or '/bp'| Open your personal backpack, if enabled |

You can currently have **three saved homes**.

For example:

`/sethome house`

Later, type:

`/home house`

This returns you to the location you saved.

You can also save locations such as `mine` or `farm`.

**Good idea:** Set a home near your base as soon as you get established!

## 5. Helpful Server Features

### 🎒 Backpacks

Everyone has access to a personal backpack with **54 storage slots**.

This gives you extra space for mining, building, and exploring.

### 📦 Automatic Inventory Sorting

NeatSort automatically organizes your inventory and chest contents when you close them.

No need to manually rearrange everything!

### 🌾 Easier Farming

The Scythe plugin allows automatic crop replanting.

- Use a hoe to harvest supported mature crops.
- You must have the required seeds.
- Your hoe loses durability during harvesting.

### 🪓 Easier Tree Cutting

Timberella allows you to chop down trees more easily.

- Works with stone, iron, gold, diamond, and netherite axes.
- Does not work with wooden axes.
- Your axe loses durability when used.

### 🔎 WhatIsThis

Look at blocks, crops, and other supported objects to see useful information automatically.

For example, you can see how far along a crop is in its growth.

### 💥 Explosion and Fire Protection

We've adjusted the server to make accidental damage less frustrating.

- Creepers should not destroy the landscape.
- Fire spreading is disabled.
- TNT is still available for mining, so use it carefully.

### 🎒 Sorter's Satchel

This special item helps you quickly put things away.

Instead of opening every chest, the satchel searches nearby storage and deposits items into chests that already contain matching items.

It's especially useful after mining, farming, or gathering supplies.

**Crafting Recipe**

Arrange these ingredients in a crafting table:

| | | |
|---|---|---|
| Leather | Ender Pearl | Leather |
| Copper Ingot | Bundle | Copper Ingot |
| Leather | Hopper | Leather |

You can use the crafted satchel or open its menu with:

`/sortersatchel open`

The command requires you to own a satchel.

**Remember:** The satchel can potentially interact with nearby chests belonging to other family members, so be careful when using it near someone else's storage.

## 7. Optional Maps for Java Edition Players

Java players can install two additional mods that make exploring much easier.

These are optional and only need to be installed on your computer.

### Xaero's Minimap

Displays a small map while you're playing.

Features include:

- A minimap on your screen
- Waypoints for important locations
- Easy navigation
- Customizable map settings

Download:

https://modrinth.com/mod/xaeros-minimap

### Xaero's World Map

Adds a larger map that you can open while playing.

It works together with Xaero's Minimap.

Download:

https://modrinth.com/mod/xaeros-world-map

### Installing Xaero's Maps Using the Official Minecraft Launcher

1. Download and install Fabric Loader from https://fabricmc.net/use/installer/.
2. Select the Fabric version matching your Minecraft Java version.
3. Download both Xaero mods from the links above. Choose the Fabric versions compatible with your Minecraft version.
4. On Windows, press **Windows + R**.
5. Enter `%appdata%\.minecraft\mods` and press Enter. Create the `mods` folder if it doesn't exist.
6. Copy both downloaded `.jar` files into that folder.
7. Open the Minecraft Launcher.
8. Select the Fabric installation and start Minecraft.
9. Join our family server normally.

These mods are client-side, meaning they do not need to be installed on our server.

Console and Bedrock players cannot use these Java mods.
