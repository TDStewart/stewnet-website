Optional Maps for Java Edition Players

Java players can install two additional mods that make exploring much easier.

These are optional and only need to be installed on your computer.

Xaero's Minimap

Displays a small map while you're playing.

Features include:

  • A minimap on your screen
  • Waypoints for important locations
  • Easy navigation
  • Customizable map settings

Download:

https://modrinth.com/mod/xaeros-minimap

Xaero's World Map

Adds a larger map that you can open while playing.

It works together with Xaero's Minimap.

Download:

https://modrinth.com/mod/xaeros-world-map

Installing Xaero's Maps Using the Official Minecraft Launcher

  1. Download and install Fabric Loader from https://fabricmc.net/use/installer/.
  2. Select the Fabric version matching your Minecraft Java version.
  3. Download both Xaero mods from the links above. Choose the Fabric versions compatible with your Minecraft version.
  4. On Windows, press Windows + R.
  5. Enter %appdata%\.minecraft\mods and press Enter. Create the mods folder if it doesn't exist.
  6. Copy both downloaded .jar files into that folder.
  7. Open the Minecraft Launcher.
  8. Select the Fabric installation and start Minecraft.
  9. Join our family server normally.

These mods are client-side, meaning they do not need to be installed on our server.

Console and Bedrock players cannot use these Java mods.
